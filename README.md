# RealmJoin Documentation

The source for the official [RealmJoin](https://realmjoin.com) product documentation, published at **[docs.realmjoin.com](https://docs.realmjoin.com)**.

RealmJoin is the application lifecycle and management companion to Microsoft Intune: deploy and maintain software from a curated catalogue of more than 3,000 applications, manage your Entra ID users, groups and devices in one unified view, and automate everyday IT operations — cloud-native, without on-premise servers.

This repository is connected to GitBook via **Git Sync**, so the published site and this repository always mirror each other.
